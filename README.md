# ⚓ use-hooks — React Custom Hooks Library

11 production-ready React custom hooks with interactive live demos.

## Hooks Included
| Hook | Category | Description |
|------|----------|-------------|
| `useDebounce` | Performance | Delay value updates — perfect for search inputs |
| `useLocalStorage` | State | Persist state across page refreshes |
| `useToggle` | State | Boolean toggle with stable callback |
| `useCounter` | State | Numeric counter with min/max/step |
| `useFetch` | Data | Fetch with loading, error, auto-cancel |
| `useAsync` | Data | Wrap any async function with state |
| `useClickOutside` | Events | Detect clicks outside a ref |
| `useWindowSize` | Browser | Reactive viewport dimensions |
| `useMediaQuery` | Responsive | CSS media query as boolean |
| `useCopyToClipboard` | Browser | Copy text with feedback state |
| `usePrevious` | State | Returns previous value of state/prop |

## Getting Started
```bash
git clone https://github.com/yourusername/react-hooks-library.git
```
